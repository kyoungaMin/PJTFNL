## 의사결정 기록

| 결정 사항 | 선택지 | 결정 | 사유 |
|-----------|--------|------|------|
| 크론 실행 방식 | Vercel 크론 유지 vs 윈도우 로컬 배치 | 윈도우 로컬 배치 전환 | Vercel 크론 에러 지속 발생, 로컬 실행이 더 안정적 |
| 배치 스케줄 관리 방식 | Task Scheduler 직접 등록 vs DB 연동 coordinator | DB 연동 coordinator | UI에서 스케줄 변경 시 Task Scheduler 수정 없이 자동 반영 |
| coordinator 실행 주기 | 1분 vs 5분 | 5분 | 1분은 불필요하게 잦음, 배치 특성상 5분 오차 허용 가능 |
| 동일 스크립트 중복 실행 방지 | 별도 lock 파일 vs Map으로 dedup | Map dedup | 간단하고 충분함 (배치는 순차 실행) |

## 이슈 / 해결

### 배치파일 한글 인코딩 오류
- **문제**: `setup_scheduler.bat`에 한글 주석 포함 시 cmd에서 깨진 문자로 명령어 오인식
- **해결**: 배치파일 내 한글 전부 제거, 영문으로만 작성

### resend 패키지 미설치
- **문제**: `package.json`에 선언되어 있으나 `node_modules`에 없어 `batch-report-email.mjs` 실행 불가
- **해결**: `npm install resend` 실행으로 해결
