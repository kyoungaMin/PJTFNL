## 변경 상세

### PeriodTable 개선 내용

**Before**
- 컬럼 레이블 고정: `전월 대비`, `4주 전 대비`, `연초 대비`
- 4주 전 기준: 항상 5번째 이전 데이터 포인트
- 연초 대비 기준: `data[0]` (전체 데이터의 첫 번째)

**After**
- 컬럼 레이블 동적 표시:
  - `freq === 'day'` → `전일 대비`
  - `freq === 'week'` → `전주 대비`
  - `freq === 'month'` → `전월 대비`
- 4주 전 오프셋:
  - `freq === 'day'` → 21포인트 (~영업일 기준)
  - 그 외 → 5포인트
- 연초 대비 기준: `_key` 또는 `d` 필드로 현재 연도(`2026-xx-xx`) 첫 번째 행을 탐색

---

## 이슈 / 해결

### 일간 지표에서 컬럼 레이블 불일치
- **문제**: BDI 같은 일간 지표에서도 `전월 대비`로 표시되어 혼란 유발
- **해결**: `ExtLayout` → `PeriodTable`로 `freq` prop 전달하여 레이블 동적 처리

### 연초 대비 기준 오류
- **문제**: 데이터 배열 첫 값(`data[0]`)이 전년도 데이터일 수 있어 연초 대비가 부정확
- **해결**: 현재 연도 문자열(`2026`)로 시작하는 첫 행을 찾아 기준점으로 사용

### 구현 상세

**표시 항목**

| 항목 | 데이터 소스 | 표시 예시 |
|------|------------|----------|
| SOX (반도체 지수) | `/api/ext-semi` → `economic_indicator.SOX` | `SOX  3,420 ▼-2.1%` |
| USD/KRW (원달러 환율) | `/api/ext-fx` → `exchange_rate.USD` | `USD/KRW  1,385 ▲` |
| 기준금리 | `/api/ext-fx` → `economic_indicator.KR_BASE_RATE` | `기준금리  3.50% →` |

**동작 방식**
- 최근 3개월 데이터를 가져와 마지막 2개 시점을 비교해 방향(▲/▼/→) 산출
- SOX는 전월 대비 변화율(%)도 함께 표시
- DB에 데이터가 없으면 카드 자체를 렌더링하지 않아 빈 상태 노출 방지
- 기존 3단계 폴백 체계(Supabase → 외부 API → MOCK) 그대로 활용, 별도 API 추가 없음

### 배경 / 이유

- 예측 화면과 외부지표 화면이 완전히 분리되어 있어 의사결정 시 탭을 오가야 하는 불편함
- 핵심 외부지표 3개를 예측 차트 상단에 요약 표시함으로써 "통합 의사결정 인터페이스" 구현
- 새 API 없이 기존 엔드포인트 재사용으로 코드 증가 최소화
