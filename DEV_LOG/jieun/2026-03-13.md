## 기능 설계 상세

### 조회 범위 선택 UX 공통 패턴

```
[데이터 조회]  [시작 ▼]  ~  [종료 ▼]
```

- 시작 드롭다운 옵션: 오래된 순 (오름차순)
- 종료 드롭다운 옵션: 최신 순 (내림차순)
- 시작 > 종료 선택 시: 종료를 시작과 동일하게 자동 스냅
- 종료 < 시작 선택 시: 시작을 종료와 동일하게 자동 스냅
- data/freq 변경 시 전체 범위로 자동 초기화

### ExternalIndicators — 인덱스 기반 범위

- `tableData` 배열의 `startIdx` ~ `endIdx` slice 사용
- `ExtLayout`, `PageExtFX` 모두 동일 방식 적용
- 전체 버튼: `setStartIdx(0); setEndIdx(tableData.length - 1)`

### WeeklyForecast — 문자열 비교 기반 범위

```ts
const filteredData = data.filter(d =>
  (!startW || d.w >= startW) && (!endW || d.w <= endW)
)
```

- 주차 키(예: `2026-W10`) 문자열 대소 비교로 범위 필터

### MonthlyForecast — 문자열 비교 기반 범위

```ts
const filteredHistory = historyItems.filter(d =>
  (!startM || d.m >= startM) && (!endM || d.m <= endM)
)
const filteredForecast = forecast.filter(d =>
  (!startM || d.m >= startM) && (!endM || d.m <= endM)
)
```

- 월 키(예: `2026-03`) 문자열 대소 비교로 범위 필터
- 차트 전체 데이터(`chartData`)는 항상 전체 기간 표시, 테이블만 필터링

## 메모

- 외부지표 `DataListTable`의 `onShowMore` 방식(더 보기 버튼)은 시작/종료 드롭다운 방식으로 완전 대체함 — UX가 더 직관적이고 원하는 구간만 즉시 조회 가능

- 조회 범위 선택 UI는 FilterBar 우측 끝에 배치하여 기존 필터(SKU, 기준일, 고객사, SOX, freq)와 시각적 일관성 유지
- dev 서버: `http://localhost:3007` (3000~3006 포트 선점 상태)
