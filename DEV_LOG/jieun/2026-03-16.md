## Vercel 배포 후 필요한 설정 (1회)

Vercel 프로젝트 설정 → **Environment Variables** 에 아래 항목 추가:

```
CRON_SECRET=임의의_비밀키_직접_설정
```

- Cron 엔드포인트에 외부에서 무단 호출을 막기 위한 인증 키
- Vercel이 Cron 실행 시 `Authorization: Bearer {CRON_SECRET}` 헤더를 자동으로 붙여 호출함

> **주의**: Vercel **Hobby 플랜**은 cron 2개까지만 지원. 3개 모두 사용하려면 **Pro 플랜** 필요.
> Hobby 플랜이라면 weekly를 monthly에 통합하거나 daily 1개로 모든 로직을 통합하는 방향으로 조정 가능.

## 이슈 / 해결

### Gold 가격 소스 오류 (GLD ETF → XAU/USD 현물가)
- **문제**: `GC=F`(선물가, $5,000+) 또는 `GLD ETF × 10`(근사치)는 실제 금 가격이 아님
- **시도 1**: FRED `GOLDAMGBD228NLBM` → 시리즈 존재하지 않음
- **시도 2**: Yahoo Finance `XAUUSD=X` → delisted로 데이터 없음
- **해결**: stooq.com `xauusd` 월간 CSV 사용 → 실제 현물가 ($5,019/oz, 2026년 3월) 정상 적재

### duplicate key 오류
- **문제**: `seed-indicators.mjs`의 delete+insert 방식에서 rows 배열 내 동일 날짜 중복 시 insert 실패
- **해결**: `upsert({ onConflict: 'source,indicator_code,date' })` 방식으로 전환 + date 기준 dedup 처리

## 메모

- `batch-daily/weekly/monthly.mjs` 스크립트는 이미 작성되어 있었으나 자동 실행 설정(cron/github actions)이 전혀 없었음 → vercel.json + API 라우트로 대체
- `batch-monthly.mjs`의 Gold 소스는 여전히 GC=F(선물가) — vercel cron monthly route에서는 stooq으로 교체 완료. batch-monthly.mjs 자체는 수동 실행 시 주의 필요
- DRAM/NAND는 DRAMeXchange·TrendForce 모두 유료 API만 제공 → 현재 MARKET 보간값 유지, 추후 유료 계약 시 업데이트 예정
