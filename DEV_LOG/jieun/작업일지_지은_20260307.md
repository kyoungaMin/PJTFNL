### 3. MonthlyForecast — 영향도 분석 동적 상관계수

**파일**: `forecastai/src/components/pages/MonthlyForecast.tsx`

- `pearson(xs, ys)` 피어슨 상관계수 계산 함수 구현
- 예측 P50 데이터와 외부 지표(FX, SOX, DRAM)를 페어링하여 실제 상관계수 계산
- DB 미연결(MOCK) 상태 또는 데이터 부족 시 기존 하드코딩 값으로 자동 fallback

- 영향도 분석 테이블에 동적 계산값 표시 (방향 화살표 + 색상 포함)

### 4. ExternalIndicators — 동적 데이터 개선

**파일**: `forecastai/src/components/pages/ExternalIndicators.tsx`

#### 4-1. FOMC / 한국은행 금통위 일정 2026년 업데이트
- 2025년 하드코딩 일정 → 2026년 연간 일정으로 교체
- `isPast(year, month, day)` 헬퍼 함수로 `done` 플래그를 현재 날짜 기준 동적 계산
- 지난 회의: 자동으로 회색(done) 처리 / 예정 회의: 색상 강조
- 헤더 라벨: "2025년 기준" → "2026년 기준"

| 기관 | 2026년 일정 |
|------|------------|
| FOMC | 1/27~28, 3/17~18, 4/28~29, 6/9~10, 7/28~29, 9/15~16, 10/27~28, 12/8~9 |
| 한국은행 | 1/15, 2/26, 4/17, 5/28, 7/9, 8/27, 10/15, 11/26 |

#### 4-2. 수입 원자재 비용 문구 동적화
- 기존: `USD 1% 상승 시 원가 약 +0.35% 압박 (수입 의존도 35% 가정)` 고정
- 변경: 실시간 USD/KRW 값 반영
  - 1,400원 초과: `현재 X,XXX원 — 고환율 위험`
  - 1,350~1,400원: `현재 X,XXX원 — 주의 구간`
  - 1,350원 이하: `현재 X,XXX원`

#### 4-3. 금(COMEX) TickerCard MOCK 배지 추가
- `TickerCard` 컴포넌트에 `isMock?: boolean` prop 추가
- Gold 카드에 `isMock` 적용 → 레이블 옆 주황색 **MOCK** 배지 표시
- DB 미수집 상태임을 UI에서 명확히 표시
