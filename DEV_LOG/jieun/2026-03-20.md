### 3. 차트 컴포넌트 예외 처리 — 0값 `null` 치환 및 선 이어그리기(`connectNulls`) 적용

#### 배경
- **산업지표** 메뉴의 'SOX 지수 추이' (7월 데이터 0)
- **글로벌수요** 메뉴의 '미국 산업/제조업 생산지수' (2, 3월 데이터 0)
- **환율/금리** 메뉴의 'USD, EUR 환율 추이' (다수의 데이터 0)
- 위 메뉴들에서 원천 데이터 누락 등에 의해 값이 `0`으로 들어오면서, 시계열 차트 그래프가 바닥을 찍고 꺾이는(망가지는) 현상이 확인됨. 과거에 유사한 조치를 했으나 일부 누락되었거나 데이터 갱신 과정에서 재발한 것으로 추정됨.

#### 변경 내용
- 차트에 주입될 데이터를 `map`으로 순회하며, 값이 `0`이거나 `null`, `NaN`, 비정상 수치인 경우 이를 강제로 `null`로 치환하는 로직을 공통적으로 적용함.
  ```typescript
  const chartData = data.map(row => {
    const newRow: Record<string, unknown> = { ...row }
    lineKeys.forEach(k => {
      const v = row[k] as number
      if (v === 0 || v == null || isNaN(v) || !isFinite(v)) newRow[k] = null
    })
    return newRow
  })
  ```
- 위 전처리를 거친 뒤 차트에 데이터를 넘김으로써, 이미 적용되어 있던 `connectNulls` 속성이 원활하게 작동하도록 유도. 즉, 값이 비어있는(`null`) 구간에서 선이 끊기거나 0으로 떨어지지 않고 양옆의 정상 데이터를 자연스럽게 이어줌.
