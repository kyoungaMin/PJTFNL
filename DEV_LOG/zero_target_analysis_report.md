## 3. Zero Target 상세 분석

### 3.1 Target 호라이즌별 Zero 비율

**3-way outer join 기반 (실제 학습 데이터에 가장 근사):**

| Target | Zero 건수 | 전체 건수 | Zero 비율 | 해석 |
|--------|-----------|-----------|-----------|------|
| **target_1w** | **75,361** | **121,834** | **61.9%** | 다음 주 수주 없을 확률 62% |
| target_2w | ~24,000 | ~113,000 | ~21% | 2주 누적이면 급감 |
| target_4w | ~3,500 | ~100,000 | ~3.5% | 4주면 거의 해소 |
| target_8w | 매우 적음 | - | <1% | 8주 누적이면 사실상 없음 |

**핵심 관찰**: 호라이즌이 길어질수록 zero가 급감 → 누적합 효과로 자연 해소

### 3.2 현재주 vs 다음주 수주 교차표 (target_1w 기준)

| 현재주 수주 | 다음주 수주 | 건수 | 의미 |
|-------------|-------------|------|------|
| =0 | =0 | 46,981 | 지속적 비활동 (매출/생산만 있는 주) |
| =0 | >0 | 24,289 | 수주 재개 (간헐적 수요) |
| >0 | =0 | 28,380 | 수주 중단 (간헐적 수요) |
| >0 | >0 | 22,184 | 연속 수주 (정규 수요) |

→ 수주가 있는 주 중 56%는 다음 주에 수주가 없음

### 3.3 제품 유형별 분포

**수명 대비 수주 커버리지 (= 수주가 있는 주 / 전체 수명 주차):**

| 커버리지 | 제품 수 | 비율 | 유형 |
|----------|---------|------|------|
| <20% | 2,548 | 43.0% | 극도로 간헐적 (스팟 수요) |
| 20-40% | 939 | 15.9% | 간헐적 |
| 40-60% | 338 | 5.7% | 준간헐적 |
| 60-80% | 140 | 2.4% | 준정규 |

- **Intermittent 수요 제품 (커버리지 <60%)**: 3,825개 (64.6%) → 총 수주량의 **88.4%** 차지

## 4. "Zero를 맞히는 것"이 유의미한 예측인가?

### 4.1 유의미한 경우 (YES)

1. **재고 최적화 관점**: "다음 주에 이 제품은 주문이 없을 것" → 불필요한 선발주 방지, 재고 비용 절감
2. **생산 계획 관점**: zero 예측 = "생산라인 전환 가능" → 가동률 최적화
3. **현재 v4 모델이 이미 2-Stage 설계**: Stage 1에서 이진분류(수요 유/무)를 별도 학습 → zero 예측에 특화
4. **Frozen Zone(1~4주) 의사결정**: 단기 zero 예측은 즉각적 발주·생산 의사결정에 직결

### 4.2 유의미하지 않은 경우 (NO / 주의 필요)

1. **Naive 모델 대비 개선이 없다면 무의미**
   - 62% zero 데이터에서 "항상 0 예측" → 정확도 62% 달성 (Zero-Rate Baseline)
   - 모델이 이를 넘지 못하면 학습한 의미가 없음
2. **1~2회 주문 제품(46.7%)의 zero 예측은 트리비얼**
   - 수명 내 1~2주만 주문 → 나머지 전부 0 → 맞히기 쉬움
   - 이 제품들은 예측 대상에서 제외하는 것이 타당 (현재 MIN_SAMPLES=26주로 필터링 중)
3. **비즈니스 가치는 "Non-Zero를 맞히는 것"에 더 크다**
   - 간헐적 수요에서 "이번 주 갑자기 주문이 들어온다" → 이것을 놓치면 납기 지연
   - Recall(재현율)이 Precision보다 중요한 비대칭 비용 구조

### 4.3 현재 모델의 Zero 대응 현황

| 요소 | 현재 설계 | 평가 |
|------|-----------|------|
| 2-Stage (v4) | Stage 1 이진분류 + Stage 2 수량 회귀 | 적절 — zero/non-zero 분리 학습 |
| ZERO_THRESHOLDS | P10=0.5, P50=0.3, P90=0.1 | P90은 관대하게 non-zero 허용 → 놓치는 주문 줄임 |
| MIN_SAMPLES=26 | 26주 미만 제품 제외 | 1-2회 주문 제품 자동 필터 |
| demand_segment 피처 | 소량(<10)/중량(10-99)/대량(100+) | 세그먼트별 zero 패턴 차이 반영 |
| zero_ratio_13w 피처 | 최근 13주 중 수요 없는 주(zero) 비율 | 간헐성 정도를 피처로 활용 |

## 5. 권장 사항

### 5.1 평가 지표 보완

현재 WMAPE/R²만 사용 중 → Zero 예측 성능을 별도 추적 필요:

| 지표 | 산식 | 의미 |
|------|------|------|
| **Zero Precision** | TP_zero / Pred_zero | "0으로 예측한 것 중 실제 0인 비율" |
| **Non-Zero Recall** | TP_nonzero / Actual_nonzero | "실제 주문이 있을 때 놓치지 않는 비율" |
| **Zero-Adjusted WMAPE** | WMAPE on non-zero subset only | 실질적 수량 정확도 |

### 5.2 데이터 전략

- **Intermittent 전용 모델** (Croston's method, TSB 등) 도입 검토 → 커버리지 <30% 제품 대상
- **Full-panel gap filling**: 현재 outer join 방식 대신, 제품 수명 구간 내 빈 주차를 명시적으로 0 채움 → shift 연산의 의미가 정확해짐
- **수주량 기반 제품 티어링**: 금액/수량 상위 200개 제품에 집중 → 비즈니스 임팩트 극대화

### 5.3 현재 구조의 잠재적 문제

⚠ **shift 기반 target 생성의 함정**: `weekly_product_summary`에서 빈 주차가 없으므로, `shift(-1)`은 "다음 행"이지 "다음 주"가 아닐 수 있음. 예: 주차 W05 → W08(W06,W07 비어있음)이면 shift(-1)은 W08의 값이 됨. 이는 target의 시간 해석을 왜곡함.
