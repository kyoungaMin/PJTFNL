## 의사결정 기록

| 결정 사항 | 선택지 | 결정 | 사유 |
|-----------|--------|------|------|
| 데이터 생성 위치 | 각 화면에서 개별 생성 vs 별도 관리 화면 | 별도 관리 화면 1개 | 의존성 순서 보장, 권한 관리, 일괄 갱신 편의성 |
| 기간 선택 방식 | 글로벌 기간 1개 vs 파이프라인별 맞춤 | 파이프라인별 맞춤 | 주/월/일 주기가 다른데 동일 선택기는 혼란 유발 |
| 기간의 의미 | A. 입력 데이터 범위 vs B. 반복 실행 | A. 입력 데이터 범위 | 비개발자 사용자에게 "이 기간의 데이터로 결과 생성"이 직관적 |
| 주차 선택 UI | 최근 N주 리스트 vs 년월→주차 2단계 | 년월→주차 2단계 | 월 선택 달력과 동일한 패턴으로 사용자 학습 부담 감소 |
| 외부지표 기간 | 즉시 실행(기간 없음) vs 일자 선택 | 일자 선택 | 과거 데이터 재수집 필요성 있음 |
