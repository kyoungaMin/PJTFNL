| 3 | KR_BASE_RATE, KR_IPI_MFG, KR_BSI_MFG | 40일 | `python DB/12_load_ecos.py` | ECOS API — 3월분 미발표 |
| 4 | 무역통계 | 3월~ | `python DB/04_load_external_data.py` | UNIPASS API — 3월분 미갱신 |

### 정기 갱신 권장 (자동화 미설정)

| 주기 | 대상 | 스크립트 |
|------|------|---------|
| 매일 | SOX, BDI, COPPER, 환율 | `15_load_realtime_indices.py` + `10_load_exchange_rate.py` |
| 매주 | DRAM, NAND, WTI | `15_load_realtime_indices.py` |
| 매월 | FRED 지표, ECOS 지표, 무역통계 | `04_load_external_data.py` + `12_load_ecos.py` |

> 현재 모든 수집 스크립트가 **수동 실행** 방식입니다.
> 정기 자동 수집(cron/스케줄러)을 설정하면 데이터 갭을 방지할 수 있습니다.

## 5. 참고: DRAM/NAND 데이터 한계

- DRAM_DDR4, NAND_TLC는 **TrendForce 유료 API**가 필요하여 실시간 수집 불가

- 실제 시장가와 차이가 있을 수 있으므로 해석 시 유의 필요
