## 추가 작업

### 시스템 기준날짜 2026-02-28 고정 (실데이터 최신일 기준)

실데이터 최신일이 2026-02-28이므로, 모든 분석·인사이트 도출의 기준을 해당 날짜로 고정함.

#### 문제 원인
- 3개 API가 `new Date()`(실서버 시간 = 2026-03-13)를 기준으로 날짜 계산
- `ai-insights/route.ts`: 이번 달(3월)에 수주 데이터 없어 GPT에게 "이번 달 수주 0건"으로 전달
- `alerts/route.ts`: 구매발주 알림 시간이 '03-13'으로 표시
- `ai-insights/route.ts` 생성 타임스탬프: "3. 13." 으로 표시

#### 수정 내용

**`forecastai/src/app/api/dashboard/route.ts`**
- 상단에 `const SYSTEM_BASE_DATE = '2026-02-28'` 상수 추가
- `const now = new Date()` → `new Date(SYSTEM_BASE_DATE + 'T00:00:00')`
- fallback 날짜·26주 시작 fromStr 모두 2/28 기준으로 통일

**`forecastai/src/app/api/ai-insights/route.ts`**
- `const SYSTEM_BASE_DATE = '2026-02-28'` 상수 추가
- `now` 기준 수정으로 GPT 프롬프트 데이터 정정:
  - `thisMonthYm`: `2026-03` → `2026-02` (2월 실데이터 반영)
  - `lastMonthYm`: `2026-02` → `2026-01`
  - `p_to_date` (재고커버리지 RPC): `2026-03-13` → `2026-02-28`
  - `dataDate` (GPT 프롬프트 오늘 날짜): `2026-03-13` → `2026-02-28`
- `generatedAt` 응답값: `cache.generatedAt`(실서버시간) → `SYSTEM_BASE_DATE + 'T00:00:00'`

**`forecastai/src/app/api/alerts/route.ts`**
- `const SYSTEM_BASE_DATE = '2026-02-28'` 상수 추가
- 구매발주 알림 `time`: `new Date().toISOString().slice(5,10)` → `SYSTEM_BASE_DATE.slice(5,10)`

**`forecastai/src/components/pages/Dashboard.tsx`**
- AI 인사이트 푸터 날짜 표시 형식 변경:
  - `toLocaleString(... hour, minute)` → `toLocaleDateString(... month, day)` (시간 제거)
  - `생성` → `기준` (표시 문구 변경)
  - 결과: "3. 13. 오후 08:09 생성" → "2. 28. 기준"
