### OpenAI API 키 발급 방법 (현재 코드 기준)

1. [platform.openai.com](https://platform.openai.com) 접속 → 로그인 (ChatGPT 계정과 동일 이메일 사용 가능)
2. 좌측 메뉴 **Billing** → **Add payment method** → 카드 등록 (최소 $5 충전)
   - ⚠️ ChatGPT Plus 구독과 별개 — API는 따로 충전 필요
3. 좌측 메뉴 **API keys** → **Create new secret key** → 키 복사
   - 창 닫으면 다시 못 보므로 반드시 즉시 저장
4. `forecastai/.env.local`에 추가:
   ```
   OPENAI_API_KEY=sk-...여기에_키_입력...
   ```
5. Next.js 개발 서버 재시작: `Ctrl+C` → `npm run dev`

### 4. 비밀번호 변경 기능 구현 방향 검토

#### 현재 코드 상태
- `Login.tsx`: "비밀번호 변경" 버튼 → 이메일 입력 모달 → `resetPasswordForEmail()` 발송 ✅
- `reset-password/page.tsx`: 링크 클릭 후 새 비밀번호 입력 폼 ✅ (세션 복원 버그 수정 완료)
- **막힌 이유**: Supabase Free 플랜 DB 용량 초과 (2.835GB / 0.5GB, 567%) → URL Configuration 설정 불가

#### 구현 방법 비교

| 항목 | Supabase 내장 이메일 | Resend + 커스텀 토큰 |
|------|---------------------|---------------------|
| 난이도 | 쉬움 (코드 거의 완성) | 중간 (API 2개 + 페이지 수정) |
| 비용 | 무료 | 무료 (월 3,000건) |
| 추가 설정 | Supabase 대시보드 URL 등록 필요 | Resend API 키 발급 필요 |
| 현재 가능 여부 | ❌ DB 용량 초과로 URL 등록 불가 | ✅ 즉시 구현 가능 |
| Supabase 의존도 | 높음 (이메일·토큰 모두 Supabase) | 낮음 (비밀번호 변경만 Supabase) |
| 토큰 만료 관리 | Supabase가 자동 처리 | 직접 구현 필요 (user_profile 컬럼) |

#### Resend 방식 구현 계획

```
[Login.tsx] 이메일 입력 → POST /api/auth/reset-request
  → user_profile에서 이메일 존재 확인
  → crypto.randomUUID()로 토큰 생성
  → user_profile.reset_token, reset_token_expires_at 저장 (1시간 유효)
  → Resend로 이메일 발송 (링크: /reset-password?token=xxx)

[/reset-password?token=xxx]
  → GET /api/auth/reset-verify?token=xxx로 토큰 검증
  → 유효하면 새 비밀번호 입력 폼 표시
  → POST /api/auth/reset-confirm: supabase.auth.admin.updateUserById()로 변경
  → 토큰 삭제 후 로그인 페이지 이동
```

**필요 작업**:
1. Supabase SQL Editor: `user_profile`에 컬럼 2개 추가
   ```sql
   ALTER TABLE user_profile
     ADD COLUMN reset_token TEXT,
     ADD COLUMN reset_token_expires_at TIMESTAMPTZ;
   ```
2. Resend 가입 → API 키 발급 → `.env.local`에 `RESEND_API_KEY` 추가
3. API 라우트 3개 신규 작성
4. `reset-password/page.tsx` 수정 (Supabase 해시 방식 → 쿼리 파라미터 토큰 방식)

### 6. 새로고침 시 로그인 유지 (세션 복원)

**현상**: 대시보드에서 새로고침하면 로그인이 풀리는 문제

**원인**: `page.tsx`에서 마운트 시 Supabase 세션 확인 로직 없음
- 로그인 시 Supabase가 localStorage에 세션을 자동 저장하지만
- 새로고침 시 `loggedIn = false`로 초기화되어 로그인 페이지로 이동

**수정 내용** (`forecastai/src/app/page.tsx`):
- `sessionChecked` state 추가 (false → 화면 미표시, 깜빡임 방지)
- `useEffect` 마운트 시: `supabaseBrowser.auth.getSession()` → `/api/me` 호출 → `Member` 복원
- 세션 없으면 → 로그인 페이지, 세션 있으면 → 대시보드 바로 진입

```
새로고침 흐름:
1. sessionChecked = false → null 렌더 (빈 화면, 깜빡임 없음)
2. getSession() → localStorage 세션 확인
3. 세션 있음 → /api/me → Member 복원 → 대시보드
4. 세션 없음 → 로그인 페이지
```
