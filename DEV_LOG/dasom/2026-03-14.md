# 개발일지 — 2026-03-14

## 오늘 작업 요약

### 1. 사이드바 내비게이션 구조 개편

#### 배경
- 업계 동향(`industry-news`)과 임원 보고서(`executive-report`) 메뉴가 신규 추가되었으나 위치가 어색한 상태
  - 업계 동향: 대시보드 바로 아래 top-level에 위치 → 핵심 기능처럼 보여 UX 혼란
  - 임원 보고서: 외부 지표 그룹 아래 top-level에 떠있어 위치감 없음
- 수주량 예측 서비스 특성상 그룹 순서도 재검토 필요

#### 변경 내용

**① 그룹 순서 변경 (`forecastai/src/lib/data.ts`)**

| 변경 전 | 변경 후 |
|---------|---------|
| 재고 관리 → 수요예측 → 최적화 → 외부 지표 | **수요예측 → 재고 관리 → 최적화 → 외부 지표** |

- 서비스 워크플로우 기준: 수요 예측 → 재고 위험 진단 → 생산·구매 최적화 순서로 자연스럽게 흐르도록 변경

**② 업계 동향 위치 변경**

- `top-level` (대시보드 바로 아래) → **외부 지표 그룹 첫 번째 항목**으로 이동
- 뉴스·동향 성격이 외부 데이터와 동일하여 같은 그룹에 묶는 것이 자연스러움

**③ 임원 보고서 위치 변경 (`forecastai/src/components/layout/index.tsx`)**

- divider 아래 단독 top-level 위치는 유지하되, 렌더링 로직 수정
- 기존: `grouped.top` 필터에 포함되어 대시보드 바로 아래에 렌더링되는 버그
- 수정: `grouped.top` 필터에서 제외 (`n.id !== "executive-report"`) + divider 아래에 명시적으로 렌더링

#### 최종 사이드바 구조

```
대시보드
── 수요예측 ──  주간 예측 / 월간 예측 / 모델 평가
── 재고 관리 ── 재고 현황 / 리스크 관리
── 최적화 ──   생산 권고 / 구매 권고 / 시나리오 분석 / AI 시나리오
── 외부 지표 ── 업계 동향 / 산업 지표 / 글로벌 수요 / 환율·금리 / 물류 / 원자재
──────────────
임원 보고서
관리자 (Admin 전용)
```
