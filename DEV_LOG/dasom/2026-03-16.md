### 1. 업계 동향 — 뉴스 출처를 네이버 API → Google News RSS로 교체

#### 배경
- 지난 세션에서 네이버 API 연동을 예정했으나, 네이버 검색 API는 신규 발급이 중단된 상태
- 국내 뉴스를 안정적으로 수집할 대안으로 **Google News RSS** 방식 채택
  - 별도 API 키 불필요, 한국어/한국 지역(`hl=ko&gl=KR`) 필터 지원

#### 변경 내용 (`forecastai/src/app/api/industry-news/route.ts`)

**① 검색 쿼리 교체**

| 변경 전 (네이버) | 변경 후 (Google News RSS) |
|-----------------|--------------------------|
| 반도체 부품 소재 시장 동향 | SK하이닉스 수주 OR 실적 |
| 반도체 공급망 이슈 | 삼성전자 반도체 수주 OR 투자 |
| 반도체 원자재 가격 | 반도체 부품 납품 |
| — | HBM 수요 AI 반도체 시장 |
| — | 반도체 공급망 소재 수출 규제 |

- 대기업 실적·수주 중심 키워드로 교체 → 실무에 직결되는 기사 수집

**② 기사 파싱 로직 신규 작성**

- RSS XML을 직접 파싱하는 `searchGoogleNewsRSS()` 함수 구현
- Google News RSS 특이사항 처리:
  - 제목 형식이 `"기사 제목 - 언론사명"` → 제목과 언론사 자동 분리
  - `<source>` 태그 우선 사용, 없으면 URL에서 언론사 추출
  - 기간 필터: 7일 이내 기사는 `when:7d`, 그 외 `when:1m` 자동 적용
- `extractXmlTag()` 헬퍼 함수 추가: CDATA 포함 XML 태그 안전 추출

**③ HTML 엔티티 정제 강화 (`stripHtml` 개선)**

- RSS에서 `&lt;a&gt;` 처럼 엔티티로 인코딩된 HTML 태그가 제목에 섞이는 문제 해결
- 처리 순서 변경: 엔티티 디코딩 먼저 → 태그 제거 순서로 수정
- `&nbsp;`, `&#160;` (줄바꿈 없는 공백), 나머지 named entity 추가 처리

**④ 화면 출처 안내 문구 변경**

```
변경 전: Naver·Tavily 뉴스 검색 + GPT 요약 · 6시간 캐시
변경 후: Google News (국내)·Tavily (국외) + GPT 요약 · 6시간 캐시
```

**⑤ 카테고리 정리 (`forecastai/src/components/pages/IndustryNews.tsx`)**

- `CATEGORY_LIST`에서 실제 분류되지 않는 `원자재`, `거시경제` 탭 제거
- `['전체', '반도체', 'AI', '공급망']` 4개로 축소

### 3. 임원 보고서 API — 리스크 데이터 null 방어 처리

#### 배경
- `get_risk_grade_summary` RPC가 `grade: null` 행을 반환하는 경우 `riskSummary["null"]` 키가 생성되어 보고서 데이터가 오염되는 버그 발견

#### 수정 (`forecastai/src/app/api/executive-report/route.ts`)

```ts
// 변경 전
for (const r of riskRows) riskSummary[String(r.grade)] = Number(r.cnt ?? 0)

// 변경 후
for (const r of riskRows) {
  if (r.grade != null) riskSummary[String(r.grade)] = Number(r.cnt ?? 0)
}
```

- `r.grade`가 null인 경우 `riskSummary`에 추가하지 않도록 방어
