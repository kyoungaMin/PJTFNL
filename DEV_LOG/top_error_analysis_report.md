## 2. 제품별 상세 분석

### 2.1 A011924 — 오차 3,075 (과소: 560 vs 3,635)

**근본 원인: 극단적 수량 변동 + 급등 추세를 이력 평균이 희석**

```
수주 시계열 (최근 활동주):
W48 |      65 |
W49 |   3,295 | ################################    ← 급등
W02 |   3,976 | #######################################
W03 |   1,700 | #################
W05 |      65 |                                     ← 다시 급감
W06 |   3,635 | ####################################  ← 실제값 (모델은 560 예측)
```

| 지표 | 값 | 의미 |
|------|-----|------|
| 커버리지 | 43주/121주 (36%) | 간헐적 수요 |
| CV (변동계수) | **1.38** | 극도로 높은 변동성 |
| 범위 | 10 ~ 7,050 | 700배 차이 |
| 최근 평균 / 이전 평균 | 2,371 / 708 | **+235% 상승 추세** |
| 자기상관 (lag-1) | 0.31 | 약한 양의 상관 |
| IQR 이상치 | 8건 | 전체 43주 중 19%가 이상치 |
| 고객 | 1개사 (100%) | **단일 고객 의존** |

**왜 모델이 틀렸나**: 직전 주(W05)가 65로 극저 → lag1 피처가 65를 반영 → 모델이 "저수요 지속"으로 판단. 그러나 이 제품은 65↔3,000+ 사이를 교대하는 **이변량(bimodal) 패턴**을 보임. 평균 기반 모델은 이 패턴을 포착하지 못함.

## 3. 오차 원인 유형화

10개 제품의 오차를 **5가지 구조적 원인**으로 분류:

### 유형 A: 이변량/톱니 패턴 (A011924, A010003)

> 수주량이 "고-저-고-저"로 교대 → 모델은 평균으로 수렴

- **특징**: CV > 0.8, 자기상관 음수, 급변 횟수 7+회
- **근본 원인**: 고객의 발주가 "대량 일괄" vs "소량 보충"의 이중 패턴
- **모델 한계**: 래그 피처가 직전 값만 볼 때, 교대 패턴의 "다음 차례"를 판별하지 못함

### 유형 B: 추세 전환/급등 (A010079, A010222, A010245)

> 최근 상승 추세가 과거 평균에 묻힘

- **특징**: 최근 평균이 이전 대비 80~235% 상승, 실제값이 역대 최고 근처
- **근본 원인**: 모델의 피처 윈도우(ma4, ma13)가 과거 저수요 구간을 포함 → 예측값 하향
- **모델 한계**: 외삽 불가 — 학습 데이터 분포 밖의 값은 원리적으로 예측 어려움

### 유형 C: 간헐 수요 중단 (A011547, A011542, A011543)

> 정기 발주 패턴이 갑자기 끊김 → Actual=0

- **특징**: 동일 고객 #1889 단독, 3~5주 주기, 같은 날 마지막 주문
- **근본 원인**: 고객사 발주 중단은 외부 이벤트 — 데이터에 사전 신호 없음
- **모델 한계**: Stage 1 분류기가 "과거에 주기적으로 왔으니 다음에도 올 것"으로 판단

### 유형 D: 수요 붕괴/급감 (A013309)

> 기존 수준에서 급격히 축소

- **특징**: 추세 기울기 음수, 최근 값이 과거 평균의 1/30 수준 (660 평균 → 최근 20)
- **근본 원인**: 제품 수명주기 말기 또는 고객 이탈
- **모델 한계**: 평균/이동평균 기반 예측은 관성이 있어 급격한 하락을 즉시 반영하지 못함

### 유형 E: 자연 분산 범위 내 오차 (A010029)

> 대량·다고객 제품의 정상 변동 범위 내 예측 실패

- **특징**: 커버리지 62%(10개 중 최고), 고객 9개사(최다 분산), 상대오차 **25%**(10개 중 최저)
- **근본 원인**: 예측 자체는 합리적이나 실제 수주가 자연 분산 범위(std=1,490) 내에서 벗어남
- **모델 한계**: 없음 — 이 오차는 모델 문제가 아닌 **수요 자체의 본질적 불확실성**에 해당

## 5. 현재 모델 유지하면서 오차를 줄이기 위한 개선 방안

### 5.1 즉시 적용 가능 (코드 수정 최소)

#### (1) 고객 집중도 기반 예측 조정

현재 `top1_customer_pct`, `customer_hhi` 피처가 있지만 시점 래그 미적용. 개선:

```
추가 피처:
- customer_order_gap: Top1 고객의 마지막 주문 후 경과 주수
- customer_cycle_regularity: Top1 고객의 주문 간격 표준편차
- customer_active_flag: Top1 고객이 최근 N주 내 주문했는지 여부
```

→ **A011547/A011542/A011543 유형**에서 "고객이 N주 이상 주문 없으면 zero 확률 상승" 학습 가능

### 5.2 중기 개선 (구조 변경)

#### (4) 제품 세그먼트별 모델 파라미터 분리

현재 v4는 전 제품 풀링. 오차 상위 제품들은 모두 **고CV + 저커버리지 + 단일고객**:

```
세그먼트 분리 기준:
- Tier A (CV < 0.5, 커버리지 > 60%): 현재 모델 유지
- Tier B (CV 0.5~1.0 또는 커버리지 30~60%): 더 짧은 윈도우 + 높은 learning rate
- Tier C (CV > 1.0 또는 커버리지 < 30%): 중앙값 기반 보수적 예측 또는 Croston's method
```

#### (5) Quantile 예측의 실질 활용

현재 P10/P50/P90을 생성하지만, 오차 상위 제품들에서:
- A011924: 실제 3,635 → P90이 이를 커버했는지 확인 필요
- A011547: 실제 0 → P10이 0을 커버했는지 확인 필요

**P10~P90 구간 커버리지가 낮으면**: 분위수 회귀의 alpha 값을 0.05/0.95로 확대하거나, 예측 불확실성이 높은 제품에 대해 별도 경고 플래그 도입.

#### (6) 이상치 탐지 후처리

모델 예측 후, 다음 조건에 해당하는 제품에 "신뢰도 낮음" 플래그:
- Top1 고객 비중 > 90% AND 해당 고객 최근 주문 gap > 평균 gap × 1.5
- CV > 1.0 AND 직전 주 수량이 평균의 20% 미만

→ 의사결정자에게 "이 예측은 불확실성이 높다"는 정보 제공
