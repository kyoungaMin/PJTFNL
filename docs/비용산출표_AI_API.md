# AI / API 연동 비용 산출표

> 작성일: 2026-03-18
> 대상: ForecastAI (반도체 부품·소재 수요예측 SaaS)

---

## 1. OpenAI (GPT-4o-mini) — AI 분석 서비스

프로젝트에서 사용하는 유일한 유료 AI 모델입니다.
사용자가 대시보드를 열 때 데이터를 분석해서 한국어 인사이트를 자동 생성합니다.

### 1-1. 사용 중인 API 엔드포인트

| API 엔드포인트 | 기능 설명 | 최대 출력(토큰) | 캐시 주기 | 월 예상 호출 |
|---|---|---|---|---|
| `/api/ai-insights` | 대시보드 핵심 인사이트 생성 | 800 | 6시간 | ~120회 |
| `/api/ai-forecast-analysis` | 제품별 수요예측 분석 코멘트 | 700 | 12시간 | ~60회 |
| `/api/ai-indicator-insight` | 외부 경제지표 해석 | 700 | 12시간 | ~60회 |
| `/api/executive-report` | 경영진 주간 보고서 생성 | 1,200 | 요청 시 | ~10회 |
| `/api/industry-news` | 해외 뉴스 번역·요약·키워드 추출 | 4,000 | 6시간 | ~120회 |

### 1-2. GPT-4o-mini 단가 (2025년 기준)

| 구분 | 단가 |
|---|---|
| 입력 (질문·데이터) | $0.15 / 100만 토큰 |
| 출력 (AI 답변) | $0.60 / 100만 토큰 |

> **토큰이란?** 글자를 잘게 쪼갠 단위입니다. 한국어 기준 대략 1글자 ≈ 1~2토큰 정도입니다.

### 1-3. 월간 예상 비용 (사용자 5~10명 기준)

| 엔드포인트 | 입력 토큰 | 출력 토큰 | 월 비용 |
|---|---|---|---|
| 대시보드 인사이트 | ~120,000 | ~96,000 | ~$0.08 |
| 수요예측 분석 | ~90,000 | ~42,000 | ~$0.04 |
| 외부지표 해석 | ~60,000 | ~42,000 | ~$0.03 |
| 경영진 보고서 | ~20,000 | ~12,000 | ~$0.01 |
| 뉴스 번역·요약 | ~240,000 | ~480,000 | ~$0.32 |
| **소계** | **~530,000** | **~672,000** | **~$0.48 (약 700원)** |

> - 캐싱 덕분에 같은 데이터를 반복 요청해도 AI를 다시 호출하지 않아 비용이 절약됩니다.
> - 사용량이 10배로 늘어도 월 ~$5 (약 7,000원) 수준입니다.

## 2. 외부 데이터 API — 전부 무료

경제지표, 환율, 원자재 가격 등을 자동으로 수집하는 데 사용됩니다.

| 서비스 | 제공처 | 수집 데이터 | 비용 | 비고 |
|---|---|---|---|---|
| **FRED** | 미국 연방준비은행 | 산업생산지수, 금리, 환율, 구리가격 | **무료** | 분당 120회 제한 |
| **ECOS** | 한국은행 | 기준금리, 제조업생산지수, BSI, 물가지수 | **무료** | API키 등록 필요 |
| **EIA** | 미국 에너지부 | WTI 원유가격 | **무료** | API키 등록 필요 |
| **data.go.kr** | 한국 관세청 | 반도체 수출입 통계 (HS8541/8542) | **무료** | 공공데이터 |
| **Google News RSS** | 구글 | 국내 반도체 업계 뉴스 | **무료** | 인증 불필요 |

## 3. Tavily — AI 웹 검색

해외 반도체 뉴스를 자동으로 검색해오는 서비스입니다.

| 항목 | 내용 |
|---|---|
| 용도 | 해외 반도체·공급망 뉴스 자동 수집 |
| 현재 티어 | **개발자(Dev) — 무료** |
| 무료 한도 | 월 1,000회 검색 |
| 현재 예상 사용량 | 월 ~120회 (무료 범위 내) |
| 프로덕션 전환 시 | Basic $25/월, Pro $100/월 |

## 4. 인프라 서비스

웹사이트를 띄우고, 데이터를 저장하고, 자동 작업을 돌리는 기반 서비스입니다.

| 서비스 | 역할 | 무료 티어 한도 | Pro 요금 |
|---|---|---|---|
| **Supabase** | 데이터베이스(PostgreSQL) + 로그인 인증 | DB 500MB, 인증 50,000명 | $25/월 |
| **Vercel** | 웹사이트 호스팅 + 자동 배치(Cron) | 대역폭 100GB (Cron은 Pro 필요) | $20/월 |
| **GitHub Actions** | 일간/주간 데이터 수집 자동화 | 월 2,000분 (공개 리포 무제한) | **무료** |

## 6. 참고 사항

- **가장 큰 비용은 인프라(Supabase + Vercel)**이며, AI 비용은 전체의 5% 미만입니다.
- **GPT-4o-mini**는 현존하는 가장 저렴한 고성능 AI 모델 중 하나로, 비용 효율이 매우 높습니다.
- 모든 AI 응답에 **캐싱(6~12시간)**이 적용되어 있어 불필요한 중복 호출이 방지됩니다.
- 개발·테스트 단계에서는 **거의 무료**로 운영 가능합니다.
- `.env` 파일에 Google Gemini API 키가 남아있으나 **현재 사용되지 않습니다** (레거시).
- 환율 기준: $1 ≈ 1,400원 (2026년 3월 기준 근사값)
