## 5. 실무 권장 사항

### 5-1. 용도별 최적 모델

| 용도 | 추천 모델 | 근거 |
|------|----------|------|
| **대량 제품 생산계획** | LightGBM (주간), Ridge (월간) | 대량 구간 WMAPE 최저, R² 최고 |
| **소량 제품 발주** | SVR Linear | 소량 MAE 2.1~21.5, 적중률 36~87% |
| **안전재고 산출 (P10~P90)** | LightGBM Quantile | 커버리지 59~68%로 불확실성 추정 최우수 |
| **빠른 재학습/업데이트** | Ridge | 학습 속도 최고, 과적합 최소 |

### 5-2. 앙상블 전략 제안

현재 단일 모델(`lgbm_q_v2`)만 사용 중이나, **구간별 모델 전환**(Segment-based Routing)을 권장:

```
수주량 ≥ 100  →  LightGBM Quantile (대량 최적)
수주량 10~99  →  SVR Linear (중량 최적)
수주량 < 10   →  SVR Linear (소량 최적)
```

이 전략을 적용하면:
- **주간 전체 WMAPE**: 53.2% → 약 45% 예상 (▼15% 개선)
- **소량 제품 MAE**: 232.3 → 21.5 (▼91% 개선)
- **±5 적중률**: 7.1% → 약 15% 예상 (▲2배 개선)

### 5-3. 향후 개선 방향

1. **구간별 자동 라우팅** 구현 — 제품별 과거 수주량 기반 자동 모델 선택
2. **Ridge 커버리지 개선** — Conformal Prediction 잔차 분위수 윈도우 최적화
3. **앙상블 가중 평균** — 모델 간 예측값의 가중 평균으로 안정성 추가 확보
4. **주기적 재학습** — 월 1회 전체 모델 재학습 파이프라인 자동화
